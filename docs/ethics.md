# Ethics

Airtime Bias is intended for educational and portfolio purposes.

## Copyright and media handling

Reality TV episodes are copyrighted media. The project should not redistribute episodes, extracted clips, extracted frames or other copyrighted visual material.

Recommended public outputs include:

- source code;
- aggregate metrics;
- plots;
- methodology;
- limitations;
- synthetic examples;
- anonymized examples when appropriate.

## Facial data

Participant reference images and facial embeddings should remain local. They should not be committed to public repositories.

The project should avoid publishing identifiable face crops unless there is a strong, lawful and clearly justified reason.

## Scope of claims

The word "bias" is used as an analytical framing for measurable asymmetry in airtime allocation. It should not be presented as proof of intentional unfairness, manipulation or misconduct.

## Affiliation

This project is not affiliated with, endorsed by or officially connected to any TV network, streaming platform, production company or reality show.
