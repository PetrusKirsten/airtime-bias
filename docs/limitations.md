# Limitations

Airtime Bias is an exploratory project and should be documented with caution.

Potential limitations include:

- scene detection errors;
- false commentary/talking-head candidates;
- missed commentary/talking-head segments;
- participant identity recognition errors;
- low confidence predictions;
- small number of episodes;
- season-specific editing styles;
- changes in lighting, camera angle, makeup or occlusion;
- ambiguity in what counts as narrative exposure;
- inability to infer editorial intent directly from screen-time metrics.

## Expected errors

The first MVP should expect errors such as:

- reaction shots incorrectly classified as commentary segments;
- group shots passing the face-size threshold;
- fast cuts split into several short segments;
- the same commentary moment split across adjacent scenes;
- unknown identity predictions when the reference gallery is weak.

## Responsible framing

Results should be framed as exploratory evidence. A pattern such as increased airtime before elimination should be described as an observed exposure pattern, not as proof that the show intentionally foreshadowed the elimination.
